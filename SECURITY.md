# AXIA public CI disclosure rules

Public CI holds synthetic contract fixtures and official simulator diagnostics only.
Never submit or upload private instructor solutions, Hidden Tests, private Git history,
student personal data, access tokens, proprietary rosbag2 logs, or raw private evidence.

Do not enable private-repo checkout in these workflows. Do not grant write/scoped secrets.
Contact the instructor privately about potential leaks. Any apparent security finding here
requires manual confirmation: the simple source pattern test is not a complete secret scan.
